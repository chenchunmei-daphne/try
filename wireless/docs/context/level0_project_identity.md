# Level 0 — 项目身份事实（Identity Context）

本文档用于描述 `wireless-cax` 项目的**最稳定身份事实**，为项目成员与大语言模型提供一个不随阶段轻易变化的全局认知起点。

本文件中的内容应被视为长期有效的项目身份定义，而非阶段性计划或推理结论。任何修改都意味着对项目身份本身的调整，需通过 Issue + PR 谨慎进行。

## 项目名称与性质

项目名称：`wireless-cax`

`wireless-cax` 是算海团队在**无线通信 CAX（Computer-Aided X）方向**上的内部长期能力建设项目仓库。

该项目不是单一科研课题的交付仓库，而是一个用于**持续沉淀无线通信领域通用建模方法、数值算法、工程实现经验与 AI 协作范式**的基础性项目。

## 项目核心定位

`wireless-cax` 的核心定位可以概括为以下三点：

- 面向无线通信领域的 CAX 能力沉淀平台
- 面向 FEALPy 与 OpenFiniteX 的应用驱动型能力孵化器
- 面向人类协作与 AI 协作的工程化知识与软件载体

该项目的长期目标是将无线通信相关的数学模型、算法实现与工程经验，逐步转化为可复用、可验证、可演进的通用能力。

## 项目在算海体系中的位置

在算海整体技术体系中，`wireless-cax` 处于“应用牵引层”，其角色是：

- 向下牵引：
  - 抽象并反哺 FEALPy（Python，多张量后端，AI 友好）
  - 抽象并反哺 OpenFiniteX（C++，高性能，工程级）

- 向上承载：
  - 无线通信方向的具体应用需求
  - 科研项目与工程项目中的真实问题与约束

`wireless-cax` 本身不追求成为最终产品，而是作为能力沉淀与验证的中间载体。

## 项目长期不变的目标

以下目标被视为 `wireless-cax` 的长期目标，不随单一项目或阶段轻易变化：

- 建立无线通信 CAX 领域可工程化的数学建模与数值计算方法体系
- 形成物理建模、数值算法与机器学习协同工作的可复用范式
- 沉淀可被人类与 AI 系统同时理解和调用的工程化知识结构
- 支撑算海团队在无线通信相关方向的持续研究与工程实践

## 项目明确不承担的职责

为避免定位模糊，`wireless-cax` 明确不承担以下职责：

- 不作为单一科研项目的最终交付仓库
- 不承诺短期内形成可直接商业化的完整产品
- 不替代 FEALPy 或 OpenFiniteX 的基础算法库角色
- 不作为个人实验或临时代码的长期存放位置

任何偏离上述定位的内容，应在引入前通过 Issue 明确讨论其合理性。

## 项目协作与演进的基本共识

围绕项目身份，团队达成以下长期共识：

- 协作优先于个人效率
- 工程留痕优先于即时决策
- 长期可维护性优先于短期便利
- 明确事实、约束与边界优先于“看起来完整”

这些共识构成了 `wireless-cax` 项目在任何阶段开展工作的基本前提。

## 本文档的使用方式

本文件适用于以下场景：

- 新成员或外部协作者快速了解项目本质
- 向大语言模型提供项目的最小稳定身份上下文
- 校验其他文档或讨论是否偏离项目长期定位

当需要描述“当前阶段在做什么”“现在的技术路线”“近期目标与约束”时，应使用更高层级的 context 文档，而不应在此文件中补充阶段性信息。
