# Level 1 — 项目当前阶段事实（Project Stage Context）

本文档用于描述 `wireless-cax` 项目**当前所处阶段的事实性信息**，为项目成员与大语言模型提供关于“现在在做什么、以及不在做什么”的统一认知基础。

本文件仅陈述**当前阶段已经确认的事实与边界**，不包含未来规划的论证过程、技术路线推演或方案比较。其内容会随项目阶段推进而更新，更新需通过 Issue + PR 完成。

## 当前阶段概述

`wireless-cax` 项目当前处于**项目启动期与基础结构搭建阶段**。

这一阶段的核心目标是：
**建立一个可长期演进的项目仓库骨架，使后续研究、工程实现与 AI 协作有清晰、稳定的落脚点。**

在当前阶段，项目关注的是“结构是否合理、职责是否清晰、协作是否可跑通”，而不是具体算法或性能指标的实现。

## 当前阶段的核心目标

在当前阶段，项目已确认并正在推进的核心目标包括：

- 搭建完整、可解释的仓库目录结构
- 明确各顶层目录的职责边界与使用方式
- 建立最小可用的文档体系，用于支撑后续协作
- 为人类成员与 AI 协作建立统一、可控的上下文入口

所有目标均围绕“为后续实质性开发创造条件”，而非直接产出算法或应用成果。

## 当前阶段各目录的事实性角色

在当前阶段，各主要目录的角色已被确认如下：

* `docs/`

  * 用于存放执行与事实层文档
  * 当前重点在于 context 与 collaboration 两类文档的建立

* `docs/context/`

  * 用于承载项目事实层上下文
  * 已确认采用分级 context 设计，用于 AI 与成员快速对齐认知

* `docs/collaboration/`

  * 用于承载协作协议与 AI 协作约定
  * 当前阶段目标是建立可执行的协作最小集

* `kb/`

  * 预留为认知与推理资产的沉淀空间
  * 当前阶段仅建立目录与边界，不要求填充内容

* `src/`

  * 作为软件实现主目录
  * 当前阶段仅确认结构，不开展大规模实现

* `agents/`

  * 作为未来智能体与自动化协作的承载目录
  * 当前阶段仅建立入口与 README，占位但不实现具体 agent

* `examples/` 与 `tests/`

  * 作为后续验证与演示的标准位置
  * 当前阶段不要求具备可运行示例

## 当前阶段明确不做的事情

在当前阶段，项目明确不开展以下工作：

* 不进行具体无线信道模型或电磁算法的实现
* 不进行性能优化、并行化或大规模数值实验
* 不引入复杂依赖或第三方库绑定
* 不对 FEALPy 或 OpenFiniteX 主仓库做实质性代码回流

上述内容将在基础结构与协作机制稳定后，再进入后续阶段。

## 当前阶段对 AI 协作的事实假设

在当前阶段，AI 被用于以下事实性用途：

* 辅助设计仓库结构与文档体系
* 辅助生成规范化文档初稿
* 辅助审视协作流程是否完整、低歧义

AI 不被用于生成最终算法结论或作为工程事实来源。

## 下一阶段的进入条件（事实性描述）

项目进入下一阶段的判据尚未完全形式化，但当前已确认的事实性条件包括：

* 仓库结构稳定，不再频繁调整顶层目录
* `docs/context/` 与 `docs/collaboration/` 的核心文档具备可执行性
* Issue + PR 协作流程可以被真实使用并跑通至少一轮

这些条件满足后，项目将进入以“具体任务与能力沉淀”为核心的下一阶段。

## 本文档的使用方式

本文件适用于以下场景：

* 向新成员说明项目当前所处阶段
* 向大语言模型提供“当前阶段事实”的上下文输入
* 校验讨论或实现是否超出了当前阶段边界

当项目阶段发生变化时，应通过更新本文件来反映新的阶段事实，而不是在其他文档中隐式修改。
